# `reprise`: a Restart-contracted UniPC sampler for Anima — design + implementation plan

*Written 2026-09-13. Status: **designed and measured offline, not implemented.**
A reference prototype (Appendix A) and the harness that produced every number
below (Appendix B) ran on the repo's own analytically-solvable GMM-flow toy
(`scripts/ab_cogent3.py`'s toy, Anima's shift=3.0). Nothing in `diffucore/` or
`backend/` was changed. Following the family's rule (docs/cogent.md,
docs/cogent3.md): this document states only what the measurements support,
including what did not work. The real-image verdict is still owed and §6 says
exactly how to get it.*

---

## 0. Summary

`reprise` is a deterministic UniPC (bh2, order 3) sampler that, on reaching the
lower edge of a *structure band* (σ ≈ 0.45), re-noises the latent **exactly
along the forward process** back up to the band's upper edge (σ ≈ 0.85) and
re-integrates the band deterministically — three times (`restarts=3`). Only the
final pass through the band is run at the schedule's full density; the first
pass and the intermediate re-integrations are cheap *drafts* (every second grid
point). Below σ 0.45 it is plain UniPC to the end. No per-step ancestral noise
anywhere.

```
σ_max ───drafts(stride 2)───► σ_lo ══jump══► σ_hi ──draft──► σ_lo ══jump══► σ_hi ──draft──► σ_lo ══jump══► σ_hi ──full───► σ_lo ──full──► 0
   [UniPC, history fresh]           [UniPC]                     [UniPC]                     [UniPC, continues to 0]
```

It is a rectified-flow adaptation of Restart sampling (Xu, Liu, Tong, Vahdat,
Kautz, Jaakkola — "Restart Sampling for Improving Generative Processes",
NeurIPS 2023, arXiv:2306.14878) with four repo-specific changes: the exact
rectified-flow forward jump; a UniPC core (fresh history per segment) instead
of Heun; a band snapped to the *user's* schedule grid so the scheduler keeps
control of σ placement; and the draft/full-pass density split, which is what
makes three restarts affordable inside a normal step budget.

**Why it should be the new default candidate.** It resolves the tension the
repo has measured three times over (uni_pc_anneal wash-out, the cogent gates
being floor-driven, the pump's "injection count is the engine"): a high-order
deterministic core wants *no* per-step noise, but prompt coherency wants many
CFG re-deciding rounds at high σ. Restarts give both — the noise is added
*between* complete ODE segments, so no divided difference ever straddles an
injection, and each restart is a full re-decision of the layout under CFG.

**What the toy says at matched NFE** (3 seeds; details in §4):

| metric (lower is better) | uni_pc_bh2 | cogent3 η=1 | cogent3_pump | secant_anneal | **reprise K3** |
|---|---|---|---|---|---|
| exact model, ED to data law @32 NFE, flow (floor 0.099) | 0.102 | 0.118 | 0.109 | 0.104 | **0.094** |
| rough model error freq 3 @32, flow | 0.368 | 0.313 | 0.310 | 0.391 | **0.229** |
| rough model error freq 6 @32, flow | 0.220 | **0.140** | — | 0.210 | 0.146 |
| CFG w=4.5, ED to cond law @32, flow | 1.586 | 0.868 | 0.919 | 0.873 | **0.636** |

The CFG rows are the ones that matter for the user's headline complaint

by 20–27 % against the family's best stochastic samplers and by 55–60 % against
deterministic UniPC, while being the *only* sampler whose sample spread matches
the truth (the per-step-noise samplers over-contract toward mode centres — the
toy's signature of the "washed-out" look the repo saw on real images; the
deterministic solvers overshoot past the modes — CFG over-saturation).

## 1. What the repo already knows (the evidence that shaped this)

Everything here is from `docs/`, `GUIDE.md`, the memory notes, and the code.

1. **Per-step ancestral noise and a high-order core fight.** `uni_pc_anneal` at
   η_max=1.0 washed out to a ghost on the 2060 (sharpness 2331 → 251); the
   σ-tied order ramp rescued coherence but quality stayed monotone-decreasing
   in η, so it ships a token η_max=0.2 decoupled from the panel knob
   (docs/uni-pc-anneal.md §5). Mechanism: divided differences of an x0 history
   that straddles an injection amplify the injected noise.
2. **The cogent gates are mostly the floor.** The measurement hook found the
   step-size floor, not the Wiener term, drives the 2nd-order gate on 35–100 %
   of a 24-step schedule (`COGENT-IMPROVE-IMPLEMENTED.md` §3). So on real
   schedules `cogent`/`cogent3` behave close to `dpmpp_2m_anneal`/3M with a
   slightly damped correction — the noise-vs-order tension is managed, not
   removed.
3. **Deterministic solvers own ≤12 steps; the annealed family owns 24–32**
   (docs/cogent.md §5) — because the family's stochasticity only pays once
   there are enough steps after the noise to clean it up.
4. **Prompt coherency comes from CFG re-deciding rounds at high σ, and the
   count is the engine, not the size.** `cogent3_pump` + `beta_mix` was the
   real-image coherency win ("holy fuck"); `pump_dual` v1 halved the injection
   count and lost it (docs/pump-scheduler-plan.md §1.1). The pump is
   hard-stopped below σ 0.45 because low-σ perturbation turns skin and
   gradients to mush (aether's failure).
5. **There is no converged reference image at CFG 4.5** — any "distance to a
   high-step reference" metric is void; real-image A/Bs must be paired
   multi-seed or human-judged (`no-converged-reference-at-cfg45`).
6. **Scheduler verdicts from the toy do not transfer to real images for the
   stochastic samplers**: the toy ranks `beta_mix` 2–4× worse than `flow` for
   the exponential core, yet `cogent3_pump × beta`/`beta_mix` won Stage A and
   the human review. So the design must work on the user's schedulers
   (`beta_mix`, `smoothstep`), not only on `flow`.
7. **The user's production settings**: `secant_anneal × beta_mix × 32`, CFG
   4.5, shift 3.0, CFG interval (0, 0.75), 1024×1536; `cogent3_pump × beta_mix
   × 28` as the coherency pick (`settings.json`, `scripts/ab_franken_sampler_sched.py`).
8. **Things already killed — do not rebuild**: lag-2 gate, `v_model`
   separation, closed-loop scheduler (`cogent4-per-channel-gate`), EasyCache
   rule, sa_solver, ACAS/flow_karras/logsnr_front schedulers, self-correcting
   variable-NFE schedulers (variable NFE breaks step accounting/previews).

Restart theory (Xu et al. 2023) says precisely what item 1 + item 4 need: the
contraction of accumulated error (discretization, model error, *and* the
off-manifold drift CFG causes) is strongest when the noise is injected in a
few large forward jumps with deterministic ODE segments in between, because a
forward jump is exact (no discretization error) while every SDE step pays
one. The paper measured exactly the trade the user cares about on Stable
Diffusion at high CFG: better text alignment *and* better FID than DDIM/SDE at
equal NFE.

## 2. The design

### 2.1 Algorithm

Inputs: the x0 denoiser closure `model(x, σ) → x0`, the initial latent, the
user's σ schedule `sigmas` (descending, trailing 0), `generator`.

Parameters (defaults are the measured optimum, §4.3):

| name | default | meaning |
|---|---|---|
| `restart_lo` | 0.45 | band lower edge, in the family-invariant `sigma_frac` coordinate (σ on flow, σ/(1+σ) on VE) — the pump's cutoff |
| `restart_hi` | 0.85 | band upper edge (must be ≥ ~0.85 to re-decide layout; §4.3) |
| `restarts` | 3 | number of re-noise + re-integrate rounds (K) |
| `draft_stride` | 2 | grid stride of the first pass through the band and of the intermediate restart passes; the final pass is always full density |
| `order`, `variant` | 3, `"bh2"` | UniPC core (same as `uni_pc_bh2` / `uni_pc_anneal`) |
| `model_type`, `shift` | `"flow"`, schedule shift | flow half-logSNR map + first-σ offset, as every flow-aware sampler here |

Steps:

1. **Snap the band to the grid.** `i_hi` = first index with
   `sigma_frac(sigmas[i]) ≤ restart_hi`; `i_lo` = first index with
   `sigma_frac ≤ restart_lo`. If either is missing, `i_hi ≥ i_lo`, or `i_lo`
   is the terminal 0 → **no restart is possible**: run `sample_uni_pc` on the
   whole schedule and return (bit-identical to `uni_pc_bh2`). This is the
   img2img/inpaint path whenever the sliced schedule starts at or below
   `restart_lo`.
2. **Band and segments.** `band = sigmas[i_hi : i_lo+1]`;
   `strided(band, s)` keeps indices `0, s, 2s, …` plus the last point (so both
   edges are always present).
   - `seg_0 = cat(sigmas[:i_hi], strided(band, draft_stride))` — σ_max → σ_lo,
     drafting the band;
   - `seg_k = strided(band, draft_stride)` for `k = 1 … restarts−1` — the
     intermediate re-integrations;
   - `seg_last = sigmas[i_hi:]` — the final full-density pass through the band,
     **continuing without a history reset all the way to 0**.
3. **Integrate `seg_0`** with `sample_uni_pc(…, lower_order_final=False)`
   (the segment does not end at 0, so no order ramp-down).
4. **For each restart segment**: jump, then integrate.
   - **Jump** σ_lo → σ_hi (`σ_lo = sigmas[i_lo]`, `σ_hi = sigmas[i_hi]`), the
     exact forward-process transition of the rectified-flow path:
     ```
     a = (1 − σ_hi) / (1 − σ_lo)                      (flow;  a = 1 on VE)
     b = sqrt(σ_hi² − a²·σ_lo²)
     x ← a·x + b·ε,   ε ~ N(0, I) drawn with `_noise_like(x, generator)`
     ```
     This is `_rf_ancestral_step`'s `renoise_coeff` algebra with
     `sigma_down = σ_lo`, `sigma_next = σ_hi`: the result has the marginal at
     σ_hi given the same x0. After the jump only `(1 − σ_hi)·x0 ≈ 0.15·x0` of
     the draft survives as signal — the layout is *seeded* by the draft, not
     kept (that is the point).
   - **Integrate** the segment with a *fresh* `sample_uni_pc` call
     (history reset — the pre-jump x0 history is stale by construction).
     Intermediate segments use `lower_order_final=False`; the last one uses
     the caller's `lower_order_final` (default True) and lands on the x0
     estimate at σ=0 as every data-prediction sampler here does.
5. **Callback / NFE.** The inner UniPC calls emit the callback once per model
   evaluation; the wrapper re-indexes them with a running counter so the
   pipeline's progress bar advances once per NFE. The exact NFE is
   `reprise_nfe(sigmas, …) = Σ (len(seg) − 1)` over the segments (§2.5), and
   the pipeline must size `_step_progress` with it.

The prototype in Appendix A is this algorithm verbatim (≈ 60 lines on top of
the existing `sample_uni_pc`).

### 2.2 Why each choice

- **Deterministic UniPC core, no η.** Items 1–2 of §1. UniPC bh2 is the
  cleanest deterministic solver the repo has measured on real Anima images
  (the eta-sweep verdict) and the toy's best at 24–32 NFE; keeping every
  segment fully deterministic means the corrector/predictor never sees an
  injection inside its history window. `restarts=0` *is* `uni_pc_bh2`.
- **Exact forward jump, not an ancestral split.** Restart's contraction
  argument needs the re-noised latent to sit on the forward marginal at σ_hi.
  The `_rf_ancestral_step` machinery does this when `sigma_next > sigma_down`;
  written out as above there is no η bookkeeping to get wrong.
- **Band 0.45–0.85.** Lower edge = the pump's measured cutoff (item 4; the
  toy confirms 0.35 and 0.55 are no better, §4.3). Upper edge: bands capped at
  0.70 do nothing for CFG error (ED 1.33 vs 0.94 at 32 NFE for K=1) because
  the re-noise keeps too much of the draft's layout; 0.90/0.95 waste draft
  steps where the model is σ-invariant and cost accuracy (§4.3). In flow-time
  0.45–0.85 is t ∈ [0.21, 0.65]: the middle of the trajectory, where the
  structure is visible enough to be judged and still cheap to change.
- **Grid-snapped band.** The restart re-integrates the *user's* grid points,
  so `beta_mix`/`smoothstep`/`flow` keep control of σ placement, the NFE is an
  integer function of the schedule, and no new scheduler is needed (item 6:
  the design has to work on the production schedulers, and §4.2 shows it does).
- **Drafts (stride 2) + one full final pass.** This is the departure from Xu
  et al. (who run every segment at the main step size). At matched NFE the
  first pass and the intermediate passes are re-noised anyway, so their only
  job is a good-enough seed; spending full density there is the wrong trade.
  Measured (§4.3, flow @32 NFE, CFG ED): K1 full 0.943 → K2 full 0.737 → K2
  drafts 0.720 → **K3 drafts 0.636**, with the exact-model accuracy held at
  the floor. One-step "drafts" (stride ∞) are too crude (K4: 0.964, worse than
  K2) — the seed must be a real integration, just a coarse one.
- **Three restarts.** K is the coherency-vs-softness dial (§4.3): ED to the
  CFG target keeps improving with K (K6: 0.475) but the sample spread starts
  to under-shoot the truth from K4 on (mode distance 15.8 → 15.5 at K6 vs
  truth 15.89) — the same over-contraction the per-step-noise samplers show,
  i.e. the wash-out direction — and exact-model accuracy leaves the floor
  (0.094 → 0.112–0.120). K3 is the knee on all three metrics simultaneously.
- **Final pass continues to 0 without reset.** The last restart's descent
  through the band and the low-σ detail phase are one continuous ODE, so
  UniPC keeps its 3rd-order history across σ_lo; only the K jumps reset it.
- **No per-step noise knob, no coherence gating of the jump.** The pump's
  `(1 − C)` spatial weighting was considered and rejected for a *large* jump:
  a spatially varying re-noise level puts the latent off the forward marginal
  the model is told it is at (σ_hi), which the pump's small amplitudes get
  away with and a 0.8-std jump would not. Isotropic keeps the theory intact.

### 2.3 Degradation invariants (to be pinned by tests)

| pin | result |
|---|---|
| `restarts=0` | bit-for-bit `sample_uni_pc(variant="bh2", order=3)` — `torch.equal`, no noise drawn |
| no grid point in the band (e.g. img2img start ≤ `restart_lo`, or `restart_hi ≤ restart_lo`) | same: bit-for-bit `uni_pc_bh2`, seed-independent |
| constant-x0 denoiser | lands exactly on the target (UniPC's final step is `x = model_prev[-1]`) — the jump changes nothing about that |
| same `generator` seed | bit-identical output; different seed ⇒ different output (stochastic only through the K jumps) |
| the jump | `a²σ_lo² + b² = σ_hi²` exactly; for flow `a = (1−σ_hi)/(1−σ_lo)` |
| NFE | model-call count == callback count == `reprise_nfe(sigmas, …)` |
| every segment | first σ of `seg_0` is `σ_max` (first-σ offset applies there only); every other segment starts at `sigmas[i_hi]`, ends at `sigmas[i_lo]` (or at 0 for the last) |

### 2.4 Cost (NFE) — what the user pays

NFE = `(i_hi) + ⌈band/s⌉ + (K−1)·⌈band/s⌉ + (n − i_hi)` with `band = i_lo − i_hi`,
`s = draft_stride`, `n` = nominal steps. At the defaults on the production
schedulers (shift 3.0):

| nominal steps | 8 | 12 | 16 | 20 | 21 | 22 | 24 | 28 | 32 |
|---|---|---|---|---|---|---|---|---|---|
| `beta_mix` NFE | 11 | 18 | 25 | 29 | **30** | 34 | 36 | 43 | 47 |
| `flow` NFE | 14 | 21 | 28 | 35 | 36 | 37 | 39 | 46 | 53 |
| `smoothstep` NFE | 11 | 18 | 25 | 32 | 30 | 34 | 36 | 40 | 47 |
| `beta` NFE | 14 | 18 | 25 | 29 | 33 | 34 | 36 | 43 | 47 |

So **`reprise × beta_mix × 21` costs 30 NFE — the parity point for the user's
32-NFE production run** — and `× 28` costs 43 (≈ a 22-step `heun`). Worked
example, `beta_mix` N=21: `i_hi=8` (σ 0.812), `i_lo=14` (σ 0.408), band 6 steps:

```
seg0 (11 NFE): 1.000 0.991 0.978 0.962 0.942 0.918 0.889 0.854 0.812 | 0.703 0.565 0.408   (draft)
jump: x ← 0.318·x + 0.801·ε
seg1 ( 3 NFE): 0.812 0.703 0.565 0.408                                                   (draft)
jump
seg2 ( 3 NFE): 0.812 0.703 0.565 0.408                                                   (draft)
jump
seg3 (13 NFE): 0.812 0.762 0.703 0.637 0.565 0.488 0.408 | 0.326 0.245 0.168 0.096 0.037 0.003 0.000   (full, continues)
```

Every matched-NFE comparison in §4 was run this way: reprise on the same
scheduler family at the largest nominal N whose NFE fits the budget (so it
ran at 30–31 NFE against baselines at 32 — a small handicap, not a bonus).

## 3. Alternatives considered (and why not)

- **Z-Sampling / zigzag with a low-CFG deterministic inversion** (Bai et al.,
  ICLR 2025): the same "re-decide at high σ" idea with a deterministic,
  guidance-gap-driven re-noise. Strong prompt-adherence results on SDXL, but it
  needs a *second* denoiser closure at a lower guidance scale — a protocol
  change in every pipeline — and the repo's evidence for *stochastic*
  re-deciding is direct (the pump win). Kept as the natural follow-up: the
  jump in step 4 could later take `x ← inv_{cfg=1}(x)` + a smaller noise.
- **CFG++ / guidance-aware re-noising**: needs the uncond x0 exposed; deferred
  in the repo for that reason already.
- **More cogent gating, lag-2, closed-loop schedules**: killed on record.
- **Restart on the gated 3M core (`cogent3`, η=0)** instead of UniPC: possible
  (the wrapper is core-agnostic), but the toy has UniPC bh2 ≥ 3M at 24–32 and
  the pipelines already special-case UniPC's kwargs; a `core=` knob is
  speculative flexibility. Not now.
- **NFE-neutral variant** (sampler carves the restart budget out of the given
  schedule): the sampler only sees `sigmas`, not the scheduler; subsampling
  the grid would silently change σ placement. The honest contract is
  "restarts cost model calls, here is the formula" — like `heun`'s 2×.

## 4. Offline evidence

Toy: `scripts/ab_cogent3.py`'s GMM-flow (512-d, 6 modes, power-law covariance,
analytic optimal denoiser, rectified flow at shift 3.0), 384 samples, 3 seeds,
energy distance (ED) to 2048 true samples. Finite-sample ED floor (384 true
samples vs the 2048): **0.099** (GMM seed 1234) / 0.106 (seed 777); a
4000-step Euler reference scores 0.102 / 0.117 — i.e. every solver at 24–32
NFE on the exact model is *at the floor*, and "A" below is a no-harm check.
Three regimes:

- **A** exact model — does the sampler distort the data law?
- **B** rough model error (`rough_error`, τ=0.35, freq ∈ {3, 6, 12}) — the
  family's proxy for a merged / imperfect velocity field.
- **C** *new*: CFG toy — cond law = modes {0,1}, uncond = all six,
  `x0 = x0_u + w·(x0_c − x0_u)` (CFG on x0 ≡ CFG on v for CONST). Metrics:
  ED to the cond law, and mean nearest-mode distance vs the true cond samples
  (15.89): above = overshoot past the modes (CFG over-saturation), below =
  over-contraction toward centres (the wash-out direction). Adherence (fraction
  landing in the cond modes) is 1.000 for every sampler at w ≥ 2, so it is not
  reported.

All matched NFE. `cogent3_pump` is run on the `[B,1,16,32]` reshape the pump
plan prescribes (the pump needs 4-D), η_max=1.0, `pump_strength=0.08`.

### 4.5 What the toy cannot say

- Nothing about *images*: no prompt, no VAE, no texture. The CFG arm models
  guidance's off-manifold push on a mixture, which is the mechanism Restart
  targets, but "mode distance" is not "detail".
- The rough-error field is high-frequency in x; `cogent3 η=1` is tuned to
  exactly that and keeps a small edge in B on `flow`/`smoothstep`. A real
  merged checkpoint's error is not this field.
- The pump's real win (prompt coherency) was called by eye; the toy never
  tested it, and it cannot here either. §6 is the only judge of that.
- At 16 NFE reprise K3 is *not* better on the exact model (A 0.135 vs 0.107)
  — like the rest of the family, it wants ≥ 24 NFE.

genuine negative to record, not a knob to tune. Record whichever outcome in
`docs/reprise.md` and the memory note.

## 7. Interactions, risks, caveats

- **CFG guidance interval.** The interval is applied in σ (the closure tests
  `sigma`), so restart passes get CFG exactly where the main pass would. At
  the production (0, 0.75) on `beta_mix` N=21 CFG is active for σ > 0.245 —
  the whole band. If a user sets an interval whose σ bound rises into the
  band (end < ~0.6 at these step counts), the restarts lose their engine —
  the same caveat the pump documents. Say so in the GUIDE bullet.
- **NFE vs nominal steps.** ~1.4–1.5× on the production schedulers (§2.4).
  The progress bar must be sized by `reprise_nfe`; the XYZ grid's per-cell
  time will look 1.5× a plain 21-step cell — that is the honest cost.
- **TeaCache.** Untested with restarts. The drift rule sees a huge input
  change at each jump and recomputes, so nothing *breaks*, but the Hermite
  forecast's residual history straddles a jump; run the A/B with TeaCache off
  and treat "reprise + TeaCache" as a separate, later measurement.
- **Live preview** will visibly rewind at each restart (drafts, then the
  final pass). Cosmetic; mention in the GUIDE.
- **img2img at low strength** silently degrades to `uni_pc_bh2` (no band in
  the sliced schedule) — by design; document.
- **Inpaint** (MaskedDenoiser pins the keep region every step): the jump
  re-noises the keep region too, consistently with the forward process, and
  the mask re-pins it on the next call. No change needed; verify once on GPU.
- **cuda_graphs / compile**: sampler-level only, no interaction.
- **At ≤ 16 NFE** reprise is not a win (§4.5); the GUIDE bullet should say
  "24+ NFE, i.e. 16+ nominal steps".
- **Restart is the paper's idea; the drafts/band/core are ours.** Cite
  arXiv:2306.14878 in the docstring; clean-room from the paper, no code taken
  from the reference repository.

## Appendix A — reference prototype (measured; port to `samplers.py`)

```python
# scratchpad/reprise_proto.py — as run for every table above
from __future__ import annotations
import torch
from diffucore.sampling import samplers as K


def restart_indices(sigmas, restart_lo, restart_hi, model_type="flow"):
    n = len(sigmas) - 1
    def frac(s):
        s = float(s); return s if model_type == "flow" else s / (1.0 + s)
    i_hi = next((i for i in range(n + 1) if frac(sigmas[i]) <= restart_hi), None)
    i_lo = next((i for i in range(n + 1) if frac(sigmas[i]) <= restart_lo), None)
    if i_hi is None or i_lo is None or i_hi >= i_lo or i_lo >= n:
        return None
    return i_hi, i_lo


def _strided(band, stride):
    """Sub-grid of a σ run keeping both endpoints."""
    if stride <= 1 or len(band) <= 2:
        return band
    idx = list(range(0, len(band) - 1, stride)) + [len(band) - 1]
    return band[idx]


def reprise_segments(sigmas, restart_lo, restart_hi, restarts, first_stride=1, restart_stride=1, model_type="flow"):
    """The σ runs the sampler integrates, in order, or None when no restart is possible."""
    idx = restart_indices(sigmas, restart_lo, restart_hi, model_type) if restarts > 0 else None
    if idx is None:
        return None
    i_hi, i_lo = idx
    band = sigmas[i_hi: i_lo + 1]
    seg_a = torch.cat([sigmas[:i_hi], _strided(band, first_stride)])
    mid = _strided(band, restart_stride)
    last = sigmas[i_hi:]
    return [seg_a] + [mid] * (restarts - 1) + [last]


def reprise_nfe(sigmas, restart_lo, restart_hi, restarts, first_stride=1, restart_stride=1, model_type="flow"):
    segs = reprise_segments(sigmas, restart_lo, restart_hi, restarts, first_stride, restart_stride, model_type)
    if segs is None:
        return len(sigmas) - 1
    return sum(len(s) - 1 for s in segs)


def _forward_jump(x, sigma_lo, sigma_hi, model_type, s_noise, generator):
    a = (1.0 - sigma_hi) / (1.0 - sigma_lo) if model_type == "flow" else torch.ones_like(sigma_hi)
    b = (sigma_hi ** 2 - (a * sigma_lo) ** 2).clamp(min=0).sqrt()
    return a * x + b * s_noise * K._noise_like(x, generator)


def sample_reprise(model, x, sigmas, *, restart_lo=0.45, restart_hi=0.85, restarts=1,
                   first_stride=1, restart_stride=1, s_noise=1.0, generator=None, callback=None,
                   order=3, variant="bh2", lower_order_final=True, model_type="flow", shift=1.0):
    common = dict(order=order, variant=variant, model_type=model_type, shift=shift)
    segs = reprise_segments(sigmas, restart_lo, restart_hi, restarts, first_stride, restart_stride, model_type)
    if segs is None:
        return K.sample_uni_pc(model, x, sigmas, callback=callback, lower_order_final=lower_order_final, **common)
    step = [0]
    def cb(i, sigma, xx, den):
        if callback is not None:
            callback(step[0], sigma, xx, den)
        step[0] += 1
    x = K.sample_uni_pc(model, x, segs[0], callback=cb, lower_order_final=False, **common)
    for k, seg in enumerate(segs[1:]):
        x = _forward_jump(x, segs[0][-1], seg[0], model_type, s_noise, generator)   # σ_lo -> σ_hi
        last = k == len(segs) - 2
        x = K.sample_uni_pc(model, x, seg, callback=cb, lower_order_final=(lower_order_final and last), **common)
    return x
```

For the shipped version: collapse `first_stride`/`restart_stride` into one
`draft_stride` (they were always equal in the chosen config; unequal settings
were measured and never better), drop `s_noise` (the jump is exact forward
noise; a scale would be a knob without a use), default `restarts=3`,
`draft_stride=2`, and add argument validation.
